# Pace Together · Claude 即時版

這個資料夾是**跑在 Claude Artifact 裡的版本**,多了需要伺服器同步的功能:

- 即時狀態(已抵達、請跑慢一點、我受傷了……),大家手機會響
- 計時、完賽成績、照片牆、紀念分享圖
- 固定團、月排行榜、我的紀錄、互相感謝

需要每個人都有 Claude 帳號,並由發起人用 email 邀請為「編輯者」。
發佈方式:在 Claude 裡請 Claude 把 `pace-together.html` 發佈成 Artifact,宣告 `capabilities.json` 裡的能力。

不想要求大家有 Claude 帳號的話,用根目錄的 `index.html`(免費、不用登入)。
